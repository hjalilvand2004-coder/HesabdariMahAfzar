# استقرار سامانه مالیار روی سرور — آدرس http://188.212.96.235:8099/

این پوشه همه‌چیز لازم برای بالا آمدن سامانه روی آدرس **http://188.212.96.235:8099/** را دارد. سه روش در دسترس است؛ روش ۱ (سرویس systemd) پیشنهاد می‌شود.

## پیش‌نیازهای سرور

- لینوکس (Ubuntu/Debian/CentOS/…) با دسترسی root یا sudo
- پایتون ۳ نصب‌شده (اسکریپت نصب خودکار محیط مجازی می‌سازد) یا Docker
- باز بودن پورت **8099/tcp** در فایروال داخلی سرور و در گروه امنیتی/فایروال ارائه‌دهندهٔ سرور

کد را روی سرور بگذارید — مثلاً با کلون مخزن:

```bash
git clone https://github.com/hjalilvand2004-coder/HesabdariMahAfzar.git /opt/maliyar
cd /opt/maliyar
```

## روش ۱ — سرویس systemd (پیشنهادی)

```bash
sudo bash deploy/install-8099.sh
```

اسکریپت به‌ترتیب: python3/venv را در صورت نیاز نصب می‌کند، محیط مجازی می‌سازد و وابستگی‌ها را نصب می‌کند، سرویس `maliyar` را روی `0.0.0.0:8099` ثبت و اجرا می‌کند، پورت ۸۰۹۹ را در ufw/firewalld (در صورت فعال بودن) باز می‌کند و در پایان تست سلامت `/api/health` را می‌گیرد.

مدیریت سرویس:

| کار | دستور |
| --- | --- |
| وضعیت سرویس | `systemctl status maliyar` |
| لاگ زنده | `journalctl -u maliyar -f` |
| توقف / اجرا | `systemctl stop maliyar` / `systemctl start maliyar` |
| اجرای مجدد | `systemctl restart maliyar` |
| ارتا با نسخه جدید | `git pull && sudo systemctl restart maliyar` |

تنظیمات دلخواه (اختیاری): `sudo MALIYAR_HOST=0.0.0.0 MALIYAR_PORT=8099 bash deploy/install-8099.sh`

## روش ۲ — داکر

از ریشه مخزن (نیازمند فایل‌های `frontend/dist` ساخته‌شده):

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

پایگاه‌داده و پیوست‌ها روی volume ماندگار `maliyar-data` (مسیر `/data` درون کانتینر) نگه‌داری می‌شوند و پس از حذف/به‌روزرسانی کانتینر از بین نمی‌روند.

## روش ۳ — اجرای مستقیم

```bash
./run.sh        # پیش‌فرض: 0.0.0.0:8099
```

## پایگاه‌داده — ماندگار و قابل پشتیبان‌گیری

- پیش‌فرض: فایل SQLite در `backend/samane.db` کنار کد؛ تمام رکوردها پس از ری‌استارت سرویس و حتی سرور حفظ می‌شوند.
- در سرویس systemd مسیر دقیق با `SAMANE_DB` (و `SAMANE_UPLOADS` برای پیوست‌ها) در فایل سرویس تنظیم شده است؛ در داکر روی `/data`.
- مسیر دلخواه: متغیر محیطی `SAMANE_DB=/مسیر/دلخواه/samane.db`
- پشتیبان‌گیری روزانه پیشنهادی:

```bash
sqlite3 backend/samane.db ".backup '/backup/samane-$(date +%F).db'"
```

## دیدن تمام رکوردها و تغییرات

- هر عملیات سامانه (ایجاد/ویرایش/حذف/تأیید/رد/ورود به سیستم و…) در جدول `audit_log` ثبت می‌شود — شامل نام کاربری، موجودیت، شناسه رکورد، شرح و زمان.
- نمایش گرافیکی: صفحه «رویدادها» در سامانه با فیلتر موجودیت و کاربر — در دسترس مدیر سامانه، مدیر مالی و حسابرس.
- اندپوینت: `GET /api/audit?entity=...&username=...` (۵۰۰ رکورد آخر، جدید به قدیم)
- تست سلامت: `GET /api/health`

## چک‌لیست پس از استقرار

1. `curl http://127.0.0.1:8099/api/health` → پاسخ `{"ok": true, "app": "samane-maliyar"}`
2. باز کردن `http://188.212.96.235:8099/` در مرورگر و ورود با کاربر مدیر (`admin` / `123456` — سپس رمز را عوض کنید)
3. صفحه «رویدادها» را باز کنید — همان لحظه ورود شما در فهرست ثبت شده است
4. تغییر رمز همه کاربران نمونه و پر کردن پروفایل شرکت از صفحه تنظیمات
